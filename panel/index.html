راهنمای اتصال سریع

راهنمای کامل در README فارسی پروژه قرار دارد.

  1. در پوشه worker دستور npm install را اجرا کنید.
  2. wrangler.toml.example و .dev.vars.example را کپی کنید و فقط روی سیستم خودتان مقدار بدهید.
  3. با Wrangler دیتابیس D1 را بسازید و migration را اجرا کنید.
  4. Secretهای Worker را با wrangler secret put تنظیم کنید.
  5. Worker را deploy کنید، سپس آدرس آن و ADMIN_TOKEN را در همین پنل وارد کنید.
  6. Webhook تلگرام را از دکمه «تنظیم وبهوک تلگرام» داخل همین پنل تنظیم کنید.
  7. برای فروش خودکار، شماره کارت/شبا یا لینک پرداخت را در بخش تنظیمات وارد کنید.
  8. مشتری در ربات با «خرید کد محصول» فاکتور می‌گیرد و بعد از پرداخت رسید را ارسال می‌کند.
